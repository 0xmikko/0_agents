# Spec

Use the complete workflow in `../blueprint/SKILL.md`. Start with the user's raw
idea, clarify only choices that materially change the product, and write Goal,
flows, metrics, constraints, reuse and invariants before discussing files or
Stages. The first owner stop locks SPEC; the second locks implementation.

Do not create a second planning document. `docs/plans/<slug>.md`, written by
`planctl`, is the source of truth.
